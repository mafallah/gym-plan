# Gym Plan PWA — Design Spec (2026-07-20)

## Purpose
A small static web app, hosted free on GitHub Pages, added to the iPhone home
screen. At GB3 it shows the current workout plan: pick today's day
(Push / Legs / Pull / Full Body), see exercises in order with sets×reps,
English + Persian names; tap a card for the animation GIF and step-by-step
instructions. Every card has a "machine taken?" toggle that flips to the swap
exercise. Plan-agnostic: the plan lives in an editable `plan.json`.

## Out of scope
No workout logging, no rest timers, no accounts. `gym-tracker.xlsx` remains
the logging tool.

## Architecture
```
Things/Gym_app/
├── exercises-dataset/     # cloned upstream repo (data source, not deployed)
└── app/                   # the deployed repo (GitHub Pages)
    ├── index.html         # app shell, vanilla JS, mobile-first, dark theme
    ├── plan.json          # editable plan: days → exercises (en/fa names,
    │                      #   sets×reps, swaps, optional dataset id override)
    ├── exercises.json     # generated by build.py: only the ~50 needed
    │                      #   records (gif URL, thumbnail, instructions.en,
    │                      #   equipment, attribution)
    ├── build.py           # matches plan names → dataset records, emits
    │                      #   exercises.json, reports unmatched
    ├── manifest.json      # PWA manifest (standalone, icons)
    ├── sw.js              # service worker: precache shell + all GIFs
    ├── icons/             # app icon + apple-touch-icon
    └── docs/spec.md       # this file
```

## Key decisions
- **GIF hosting:** hotlink `raw.githubusercontent.com/hasaneyldrm/exercises-dataset`
  URLs; do NOT copy Gym Visual media into the public app repo. Show
  "© Gym Visual" attribution in the app. Service worker caches GIFs after
  fetch so the app works offline at the gym (~15 MB cache).
- **Matching:** `build.py` fuzzy-matches plan exercise names to dataset names;
  any exercise may pin an explicit `dataset_id` in plan.json to override.
  Unmatched exercises (e.g., plank variants) render as text-only cards.
- **Plan updates:** edit plan.json → run `python3 build.py` → git push.
- **Initial plan:** Month 2 plan (`~/Things/gym_plan/next_month_plan.md`),
  4 days, incl. cardio finishers and universal rules (warm-up, weight
  selection, progression).

## Error handling
- Unmatched/missing dataset record → text-only card, no crash.
- Offline before first full precache → shell loads, missing GIFs show a
  placeholder box with the exercise name.
- plan.json schema errors → build.py fails loudly with the bad entry.

## Testing
- build.py: assert every plan exercise resolves (matched or explicitly
  text-only); print match table for human review.
- Playwright smoke test on iPhone viewport: day navigation, swap toggle,
  GIF render, service worker registration.

## Deployment
Public repo `gym-app` (user's GitHub) → GitHub Pages from main branch root →
open URL in iOS Safari → Add to Home Screen.
